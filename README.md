원피스 언리미티드 어드벤처 한글패치 v0.1
닌텐도 Wii 일본판 《원피스 언리미티드 어드벤처》 전용 한국어 패치입니다.
v0.1은 테스트 버전입니다. Wii 실기에서의 구동은 아직 검증되지 않았으며, 일부 이벤트 자막의 표시 시점이나 게임 진행에 문제가 발생할 수 있습니다.

한글화 적용 내용
- 게임 내 메뉴, 인터페이스 및 각종 안내 문구
- 아이템·도감 등 게임 내 설명 텍스트
- 한국어 글꼴 및 일부 UI 이미지
- 일부 3D 이벤트 장면의 한국어 대사 자막
- 이벤트 동영상의 한국어 자막
원작 일본어 음성은 그대로 유지됩니다.
지원 게임
- 게임: 원피스 언리미티드 어드벤처 (Wii 일본판)
- 게임 ID: RIPJAF
- 입력 파일: 일본판 순정 RVZ 또는 ISO
- 미지원: 미국판·유럽판 및 이미 수정된 게임 이미지
한글패치 적용 방법
1. 배포용 패치툴 **OnePiece_UA_KR_Patch.exe**를 실행합니다.
2. 일본판 ROM 항목에서 본인이 소유한 정품 게임으로부터 추출한 순정 RVZ 또는 ISO 파일을 선택합니다.
3. 생성 파일 항목에서 한글패치 결과물을 저장할 위치와 파일명을 지정합니다. Dolphin 사용 시 RVZ를 권장하며 ISO도 선택할 수 있습니다.
4. 임시 작업 폴더를 지정합니다. 최소 15GB, 권장 20GB 이상의 여유 공간이 필요합니다.
5. 한글패치 생성을 누른 뒤 완료 메시지와 검증 결과를 확인합니다.
6. 새로 생성된 한글판 RVZ 또는 ISO 파일을 사용합니다.
배포용 패치툴은 단일 EXE이며 별도의 CSV·이미지 파일이나 Python 설치가 필요하지 않습니다. 원본 게임 파일은 덮어쓰지 않습니다.
Dolphin 사용 시 필수 설정
Dolphin에서 글자가 잘못 표시되거나 잠깐 다른 글자로 보이는 문제를 방지하려면, 텍스처 캐시 정확도를 안전(Safe)으로 설정해 주세요.

게임별 설정을 직접 편집하는 경우, 사용자 설정 폴더의 GameSettings/RIPJAF.ini에 아래 항목을 지정할 수 있습니다.
[Video_Settings]
SafeTextureCacheColorSamples = 0
설정을 변경한 뒤 Dolphin을 다시 실행해 주세요. 다른 게임에 영향을 주지 않도록 이 게임에만 적용하는 설정을 권장합니다.
주의사항
- 정품 Wii 일본판 게임을 소유한 사용자만 이용해 주세요. 본인이 소유한 정품에서 적법하게 추출한 게임 파일을 사용해야 합니다. 패치툴에는 게임 원본이 포함되어 있지 않습니다.
- Wii 실기 구동은 미검증입니다. Dolphin에서도 v0.1 전체 구간의 실제 플레이 검증은 완료되지 않았습니다.
- 일부 3D 이벤트 장면 및 동영상의 자막 싱크, 버튼 입력에 따른 진행 등에 문제가 있을 수 있습니다.
- 적용 전 원본 게임 파일과 세이브 데이터는 별도로 보관해 주세요.
